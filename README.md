## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/your-username/trintz-website.git

cd trintz-website

npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
